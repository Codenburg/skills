## Activation Contract

Load this skill when the user asks to build web components, pages, artifacts, posters, applications, or any frontend UI. Use when the goal is production-grade code with distinctive visual design — not generic "AI slop" aesthetics.

## Hard Rules

- Choose a BOLD aesthetic direction before writing any code: brutally minimal, maximalist chaos, retro-futuristic, organic, luxury, editorial, brutalist, art deco, etc.
- NEVER use generic AI aesthetics: Arial/Inter/Roboto, purple gradients on white, predictable layouts, Space Grotesk every time.
- Vary between light and dark themes, different fonts, different aesthetics between generations.
- Match implementation complexity to the aesthetic vision. Maximalist = elaborate code. Minimalist = restraint and precision.
- All output must be working, production-grade code (HTML/CSS/JS, React, Vue, etc.).

## Design Thinking Process

Before coding, commit to a direction:

- **Purpose**: What problem does this interface solve? Who uses it?
- **Tone**: Pick an extreme — not a middle ground.
- **Constraints**: Framework, performance, accessibility requirements.
- **Differentiation**: What makes this UNFORGETTABLE?

Then implement working code that is visually striking, cohesive, and meticulously refined in every detail.

## Aesthetics Guidelines

| Element | Rule |
|---------|------|
| **Typography** | Choose distinctive, characterful fonts. Pair display + body. Avoid generic system fonts. |
| **Color** | Commit to a cohesive palette with CSS variables. Dominant colors + sharp accents. |
| **Motion** | CSS-only for HTML, Motion library for React. One well-orchestrated load > scattered micro-interactions. |
| **Spatial** | Unexpected layouts. Asymmetry, overlap, diagonal flow, grid-breaking. |
| **Backgrounds** | Gradient meshes, noise textures, geometric patterns, layered transparencies, grain overlays. |

## Output Contract

Return the implemented component/page with:
- Aesthetic direction chosen and why.
- Key design decisions (typography, color palette, layout).
- Working production code.
- Accessibility considerations.
